About Echoes in the Mist

Echoes In The Mist is a side scrolling endless runner game for web browsers. It is set in a magical forest guarded by giant red beetles. The player controls a red hooded whose purpose is to avoid the beetles and get out of this endless forest. The player must keep running and increase the score.

The game includes very few and easy controls. The red hooded creature continuously runs to the right with increasing speed and the player needs to press Space to jump over the beetles to avoid them. The game can be paused by pressing the 'P' key on the keyboard. If the game is over, the player can start again and beat the previous highscore.

Echoes in the Mist is a WebGL based video game and it can be played from any desktop browser here
